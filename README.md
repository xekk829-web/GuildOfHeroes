## Собственный проект

Тема проекта: музыкальная коллекция

Главный класс: Music

Почему этот объект нужен программе:
Объект представляет собой альбом или композицию, из которых складывается коллекция.

Какие данные хранит объект:

- Название
- Артист
- Тип релиза
- Год
- Оценка
- Количество оценок

Какие значения задаются через конструктор:
Название, Артист, Год

Какие значения можно задавать автоматически:
Тип релиза (по умолчанию "Album"), Оценка (по умолчанию 0), Количество оценок (по умолчанию 0)

Какое действие добавлено:
Добавлен метод `AddRating()`, который добавляет оценку в общий рейтинг объекта

Что получает параметр:
Параметр получает переменную `rate` - оценку пользователя

Какой отказ проверен:
Проверено, что `rate` не должен быть меньше 0 и больше 5
